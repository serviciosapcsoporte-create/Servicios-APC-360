# Analítica de video con IA para ferreterías en Bogotá: orden, arqueo y datos en tiempo real

Ejemplo operativo típico en ferretería bogotana.

Cámaras IR tradicionales entregan imagen gris de noche y el arqueo manual toma 45 minutos.

Con Hikvision ColorVu 4K + IA YOLO: Accesos con trazabilidad, arqueo asistido en 2 minutos y mapas de calor para ordenar el layout.

Bonus: Datos en tiempo real en WhatsApp y dashboard para decisión.

Resultado 1: accesos con trazabilidad en segundos (flujo tipo)

Flujo tipo en rampa trasera (zona restringida)

  • La IA detecta persona en zona restringida fuera de horario
  • Clasifica vehículo y bultos en movimiento en la misma ventana
  • Genera clip de 10 segundos con hora y zona

Lo que vio la IA (ColorVu 4K + YOLO):

  • Detección intrusión zona rampa trasera 02:14:22 → Alerta Telegram/WhastApp gerente + clip 10s
  • Detección vehículo + placa → YOLO detecta moto-cargo + lee placa registrada (ColorVu 4K: placa nítida 2am)
  • Detección objetos → 3 bultos > 30cm moviéndose zona restringida
  • Alerta multi-canal → Gerente recibe en WhatsApp a las 02:14:25 (3 segundos)

Acción gerente: ve el clip en el celular, verifica hora y zona, y deja el evento registrado placa registrada + ubicación exacta GPS

El evento queda registrado para revisión y reporte del día

> Sin IA + ColorVu 4K: Cámaras IR viejas → "mancha gris" → sin trazabilidad → revisión manual de horas sin evidencia ordenada.

Cómo funciona el Arqueo IA:

```

  • YOLO detecta: Apertura cajón + sonido "ding" + billetes visibles
  • OCR opcional / Conteo visual IA → Monto detectado en video
  • API Webhook POS → Obtiene monto ticket exacto mismo timestamp
  • Comparación: Monto Video = Monto POS → ✅ CUADRA / ❌ ALERTA
  • Reporte diario PDF/Excel + Clips 10s validación → Telegram/Email gerente

```

Resultado 3: mapa de calor para ordenar el layout (flujo tipo)

Mapa de calor IA (Semana 1-4 Marzo):

```

ZONA TORNILLOS (Esquina fondo) → 🔴 78% ocupación (ZONA MUERTA)

PASILLO CENTRAL → 🟡 45% (Normal)

CAJAS → 🟢 85% (Alta rotación)

```

Hallazgo: Zona tornillos = "rincón muerto" → clientes no llegan, productos no rotan, baja rotación por ubicación, no por demanda.

Acciones tomadas (Abril 2025):

  • Reubicación exhibidor tornillos → centro pasillo principal
  • Señalética "Tornillos Especializados →"
  • Demo en vivo mostrador (tornillo + taladro)
  • Iluminación LED focal + ColorVu 4K existente cubre zona

Resultado (Mayo-Julio 2025):

  • Ventas zona optimizada: mejora la rotación vs trimestre anterior
  • Rotación inventario: 2.1x → 3.8x
  • Diferencias en zona: 0 (antes 2-3/mes)
